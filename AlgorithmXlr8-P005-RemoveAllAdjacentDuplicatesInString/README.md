# Remove All Adjacent Duplicates In String

**Difficulty:** `Easy`

## Problem

You are given a string s of lowercase English letters. A duplicate removal consists of choosing two adjacent and equal letters and removing them. Repeat this process until no more duplicate removals can be made, then return the final resulting string (guaranteed unique).

Read s from standard input. Print the final result, or "(empty)" if it fully cancels out.

## Examples

### Example 1

**Input**
```
abbaca
```
**Output**
```
ca
```

**Explanation:** "bb" cancels, bringing the two "a"s together, which also cancel, leaving "ca".

### Example 2

**Input**
```
azxxzy
```
**Output**
```
ay
```

**Explanation:** "xx" cancels, bringing the two "z"s together, which also cancel, leaving "ay".
