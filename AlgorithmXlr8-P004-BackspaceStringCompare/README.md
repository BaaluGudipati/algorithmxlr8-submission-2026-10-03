# Backspace String Compare

**Difficulty:** `Easy`

## Problem

Given two strings s and t, return true if they are equal when both are typed into empty text editors, where '#' represents a backspace character (deleting the previously typed character, if any).

Read s and t, each on its own line, from standard input. Print "true" or "false".

## Examples

### Example 1

**Input**
```
ab#c
ad#c
```
**Output**
```
true
```

**Explanation:** Both strings simulate to "ac".

### Example 2

**Input**
```
a#c
b
```
**Output**
```
false
```

**Explanation:** s simulates to "c"; t is "b"; they differ.
